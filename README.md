## 🚀 Deployment & Development

### Local Installation

1.  **Clone the Repository**
    ```bash
    git clone https://github.com/visal2002/vishal_chettri_portfolio.git
    cd vishal_chettri_portfolio
    ```

2.  **Install Dependencies**
    ```bash
    npm install
    ```

3.  **Launch Environment**
    ```bash
    npm run dev
    ```
